# Top5 场景正负例区分力不足 — 根因分析与解决方案

> 分析日期：2026-05-21  
> 问题：真实视频正例和负例在 top5 场景下的综合得分与各维度得分均未有效区分  
> 分析范围：D1 身份一致性 / D3 生物特征异常 / D4 运动逻辑 / D5 物理常识 / D7 时间一致性

---

## 一、问题现象

经过对真实正例视频（高质量/无异常）和负例视频（AIGC 典型瑕疵）的评测对比，发现：

1. **综合分（final_score）差异极小**：正例和负例的综合分重叠严重，无法通过分数区分好坏
2. **五个维度得分扁平均一**：多数维度正负例均得 0.75-0.95，缺乏辨识力
3. **个别严重异常的维度被平均效应掩盖**：即使某维度分极低（如 0.3），加权平均后综合分仍在中上区间

---

## 二、根因分析

### 根因 1：各维度存在结构性"天花板效应"

多个维度的评分公式天然偏向高分，即使存在真实异常也难以显著降低。

#### 2.1 D1 人脸身份一致性

**评分公式**：
```
identity_score = clip(0.4 × csim_ref + 0.3 × csim_adj + 0.2 × csim_min - 0.1 × drop_penalty, 0, 1)
```

**问题**：
- 对单一人脸的 AIGC 视频，cosine similarity 自然在 0.7-0.95 之间（同一人物的面部嵌入高度相似）
- 只有发生"人脸替换/突变"时才触发 drop_penalty（阈值 0.3）
- **大多数 AIGC 负例并没有人脸身份变化**，角色从头到尾是同一个人 → `identity_score ≈ 0.85`，与正例无异
- 该维度对"画面内容异常但身份不变"的视频**零区分力**

**影响**：正例 ≈ 0.88，负例 ≈ 0.85，几乎无差异

---

#### 2.2 D3 生物特征异常

**扣分规则**：
```
low: 0.02 / medium: 0.05 / high: 0.10
bio_quality_score = clip(1.0 - sum(penalties), 0, 1)
```

**问题**：
- 单条异常扣分过小：5 个 "medium" 异常仅扣 0.25，得分仍为 0.75（落在"良好"区间）
- 要跌入 "critical" (< 0.50) 需要 ≥ 10 个 medium 或 ≥ 5 个 high 异常
- **实际情况**：典型 AIGC 负例只有 2-4 个 medium 异常（如手指融合 + 嘴部变形 + 关节弯曲）→ 得分 0.80-0.90
- 评分本质上是**计数型扣分制**，而非**严重度加权制**：3 个 high 异常和 5 个 low 异常对视频的破坏性完全不同，但当前只依赖数量
- L3 MLLM 兜底判定为**二值输出**（异常=0.3，正常=1.0），无中间灰度

**影响**：正例 ≈ 0.98，负例 ≈ 0.82，差异仅 ~0.16

---

#### 2.3 D4 运动逻辑与平滑度

**动态度评分**（dynamics_scorer.py）：
```
# 测量的是"运动量"，不是"运动质量"
flow_score = sigmoid(mean_optical_flow_magnitude)  # 基于光流幅度的 sigmoid
spatial_score = clip(moving_pixel_ratio)            # 运动像素占比
temporal_score = sigmoid(std_of_flow_magnitude)     # 光流幅度的时序标准差
```

**问题**：
- 动态度衡量的本质是**"画面内发生了多少运动"**，而非**"运动是否合理自然"**
- 一段剧烈但合理的运动（如跑步）和一段剧烈但畸形的运动（如 AI 生成的角色抽搐）可能获得相同的动态度分
- 该维度名为"运动逻辑"，实则只做到了"运动量测量"——缺失了"逻辑"层面的评判

**平滑度评分**（smoothness_scorer.py）：
```python
velocities = np.diff(magnitudes)
accelerations = np.diff(velocities)
max_acc = np.max(np.abs(accelerations))
normalized = np.abs(accelerations) / (max_acc + 1e-8)  # ← 自归一化
return clip(1.0 - mean(normalized), 0, 1)
```

**问题**：
- **除以 max_acc 的自归一化是核心缺陷**：无论视频整体加速度多大，归一化后均值趋近 0.5
- 一段**始终剧烈抖动**的视频（每帧加速度 = [100, 100, 100, 100]）→ normalized = [1, 1, 1] → score = 0.0（低分，正确）
- 但一段**始终平滑**的视频（加速度 = [1, 1, 1, 1]）→ normalized = [1, 1, 1] → score = 0.0（**低分，错误！**）
- 实际上 max_acc 是离群值主导的，使得大部分帧的 normalized 值在 0.1-0.3 之间，score 稳定在 0.7-0.9
- **良性与劣性运动获得相近的 smoothness 分**

**自然度 MLLM**：
- 仅在 smoothness < 0.8 时触发 → 大量 smoothness 0.8+ 的视频跳过自然度判定
- 二值输出（natural=1.0, unnatural=0.3）→ 无分级

**加权融合**：
```
motion_logic_score = 0.3×dynamics + 0.4×smoothness + 0.3×naturalness
```
- smoothness 权重最高（0.4），但其区分力最弱 → 拖累了整体维度的区分力

**影响**：正例 ≈ 0.76，负例 ≈ 0.71，差异极小

---

#### 2.4 D5 物理常识一致性

**评分路径**：
```
physics_score = VLM判定值（MLLM开启时）
              = 1.0 - drift_events × 0.3（MLLM关闭时）
```

**问题**：
- **VLM 关闭时**：仅检测像素漂移事件（光流方向一致的像素块），大多数物理常识违规（如重力异常、液体反重力、碰撞缺失）**不表现为像素漂移**
- 像素漂移检测的是"物体是否在画面中匀速滑动"，但：
  - 重力异常 → 物体悬浮而非漂移
  - 碰撞缺失 → 物体穿模而非漂移
  - 液体异常 → 形态变化非漂移
- 典型负例的 `drift_events` 可能为 0 → `physics_score = 1.0`
  
- **VLM 开启时**：VLM 返回的 `physics_score` 取决于 prompt 质量与模型能力，但当前 prompt 更关注可见物理违规，对隐式物理常识（如光影方向、重力方向一致性）覆盖不足

**影响**：无 MLLM 时正例 ≈ 0.95，负例 ≈ 0.90（差异极小）；有 MLLM 时依赖外部模型，行为不可控

---

#### 2.5 D7 时间一致性（TCS-lite）

**评分公式**：
```
temporal_coherence_score = max(0.0, 1.0 - abnormal_events / total_events)
```

**问题**：
- 基于 Grounding DINO 抽样检测 + IoU 轨迹追踪
- 仅检测**目标的异常出现/消失**，事件分类中 edge_emerge/vanish、small_emerge/vanish、detect_gap 均视为"正常"
- 只有 `reason == "abnormal"` 才扣分
- **大量 AIGC 负例中，所有物体从始至终存在于画面内** → total_events = 0 → score = 1.0
- 该维度对"内容稳定无增删"的负例**零贡献**
- 即使有异常事件，如果总量少（如 1/3 abnormal → score = 0.67），区分力有限

**影响**：正例 ≈ 1.0，负例 ≈ 0.92（有事件时）或 1.0（无事件时）→ 不稳定且多数情况无区分力

---

### 根因 2：加权平均消除了单维度异常信号

**当前聚合逻辑**（`evaluation_pipeline.py`）：
```python
final = sum(v.weight * v.score for v in active.values())
```

Top5 场景下的权重（归一化后约为均权）：
| 维度 | 原始权重 | 归一化后 ≈ |
|------|---------|-----------|
| face_identity | 0.12 | 0.20 |
| biological_anomaly | 0.15 | 0.24 |
| motion_logic | 0.12 | 0.20 |
| physics | 0.12 | 0.20 |
| temporal_coherence | 0.10 | 0.16 |

**问题**：
- 假设一个视频：D1=0.88, D3=0.82, D4=0.71, D5=0.90, D7=1.0
- 综合分 ≈ 0.86 → 落在"优秀"区间
- 实际上 D3 和 D4 已表现出明显异常迹象，但被其他高分维度平均掉
- **平均聚合假设各维度独立性成立，但未考虑：一个维度的严重异常足以断言视频不合理**

---

### 根因 3：MLLM 的"二值输出"损失了信号精度

两个关键 MLLM 判定点都是二值的：

| 模块 | 判定逻辑 | 正常分值 | 异常分值 |
|------|---------|---------|---------|
| D3 L3 (bio MLLM) | `has_anomalies` → True/False | 1.0 | 0.3 |
| D4 naturalness | `is_natural` → True/False | 1.0 | 0.3 |

**问题**：
- 二值判定丢失了异常的**严重程度信息**
- "手指轻微变形"和"整个手臂扭曲断裂"都被 D3 L3 打上 0.3
- "运动略不自然"和"运动完全反物理"都被 D4 naturalness 打上 0.3
- 理想情况下应输出 [0, 1] 连续值或至少 3-5 级制

---

### 根因 4：各维度"适用性跳过"带来维度数量不一致

当某维度不适用（如无面部 → D1 skip，无光流 → D4 skip），权重重新归一化：
- 4 个维度时的均值效应比 5 个维度更强
- 跳过的维度往往是"最应该暴露问题"的维度（如无面部 → 无法检测生物异常 → 但视频确有问题）

---

## 三、解决方案

### 方案 A：修复各维度评分公式（中短期，优先级最高）

#### A1. D1 人脸身份一致性

**问题**：对单一人脸视频缺乏区分力

**方案**：
1. **增加"人脸质量信号"**：引入人脸检测置信度、landmark 稳定性、人脸朝向一致性等附加信号
   ```
   identity_score = 0.6 × cosine_similarity_score + 0.4 × face_quality_score
   ```
   其中 `face_quality_score` 综合人脸 landmarks 的帧间稳定性、遮挡程度、姿态突变等
   
2. **将一致性从"有/无突变"改为"渐变度量"**：
   - drop_threshold 从 0.3 降至 0.15，提高灵敏度
   - drop_penalty_weight 从 0.1 升至 0.25，增大惩罚力度

#### A2. D3 生物特征异常

**问题**：扣分太小，异常数小时得分不敏感

**方案**：
1. **调整为非线性扣分模型**：使用平方根或指数衰减
   ```python
   # 当前（线性）：5 个 medium = 0.25 扣分 → score = 0.75
   # 改进（加速衰减）：
   penalty = anomaly_count ** 0.7 × base_penalty
   # 1 medium = 0.05, 3 medium = 0.11, 5 medium = 0.18, 10 medium = 0.42
   ```

2. **引入异常严重度加权**：high 异常权重提升
   ```
   high: 0.20 (原 0.10), medium: 0.08 (原 0.05), low: 0.03 (原 0.02)
   ```

3. **按部位加权**：身体>手部>眼部>嘴部
   ```
   bio_score = clip(1.0 - (body×0.4 + hand×0.3 + mouth×0.2 + eye×0.1), 0, 1)
   ```

4. **L3 MLLM 输出连续分值**：要求 MLLM 返回 0-1 的严重度分数，而非二值
   - Prompt 修改：`请给出 0-1 之间的连续异常严重度评分`
   - 或至少返回 mild/moderate/severe 三级

#### A3. D4 运动逻辑

**问题**：动态度=运动量测量，平滑度=自归一化导致区分力丧失

**方案**：
1. **修复平滑度自归一化问题**：使用全局绝对阈值替代除以 max
   ```python
   # 改为基于绝对加速度阈值的评分
   ABS_ACC_THRESHOLD = 2.0  # 根据实际数据校准
   normalized = np.clip(np.abs(accelerations) / ABS_ACC_THRESHOLD, 0, 1)
   return clip(1.0 - mean(normalized), 0, 1)
   ```

2. **动态度增加"合理性"维度**：不仅测运动量，还检测异常运动模式
   - 检测周期性运动缺失（如走路应有节奏，AIGC 走路常无节奏）
   - 检测运动方向突变（方向变化 > 90° 且无外力解释）
   - 检测主体与背景运动不一致（前景/背景光流方向差异）

3. **降低 MLLM 触发阈值**：将 `naturalness_smoothness_threshold` 从 0.8 降至 0.6
   - 当前 0.8 → 大部分视频不触发 MLLM
   - 改为 0.6 → 更多视频落入 MLLM 判定范围

4. **MLLM 自然度输出连续分值**：同 A2，将 is_natural 改为 naturalness_score (0-1)

#### A4. D5 物理常识

**问题**：无 MLLM 时像素漂移覆盖不足

**方案**：
1. **扩展 VLM 关闭时的降级策略**：
   - 增加重力一致性检查（基于深度估计 + 物体分割 + 时序运动方向）
   - 增加穿模检测（基于 SAM 分割 + 实例间交并比变化）
   - 增加光影一致性（基于图像亮度的帧间变化模式）

2. **VLM prompt 优化**：添加更多物理常识检测点
   - 重力方向一致性
   - 碰撞反馈（物体接触后是否有形变/反弹）
   - 流体运动（液体是否符合 Navier-Stokes 视觉特征）
   - 刚体运动（物体是否无理由形变）

#### A5. D7 时间一致性

**问题**：仅检测出现/消失，大多数负例无此问题

**方案**：
1. **扩展检测范围**：
   - 检测物体**瞬移/跳变**（同 track 的 bbox 位置突变）
   - 检测物体**尺寸突变**（同 track 的 bbox 面积突变，非 grow/shrink 可解释的）
   - 检测物体**纹理突变**（同 track 的物体外观颜色直方图跳变）

2. **引入连续评分替代比例评分**：
   ```
   # 当前：abnormal / total_events（离散比例）
   # 改进：综合所有事件的严重度
   score = clip(1.0 - sum(event_severity) / max_penalty, 0, 1)
   ```

### 方案 B：改进聚合策略（中长期）

#### B1. 从"加权平均"改为"最小值惩罚"

```
# 当前（平均聚合）
final = weighted_average(scores)

# 改进（最小值感知聚合）
final = 0.3 × weighted_average(scores) + 0.7 × min(scores)
```
或使用调和平均（harmonic mean），对低分更敏感：
```
final = len(scores) / sum(1/s for s in scores)
```

#### B2. 引入"瓶颈维度"概念

定义：任一维度低于阈值 → 综合分强制降级
```python
if any(score < 0.3 for score in scores):
    final = min(final, 0.4)  # 有任意维度极差 → 综合分不超过 0.4
elif any(score < 0.5 for score in scores):
    final = min(final, 0.6)  # 有任意维度差 → 综合分不超过 0.6
```

#### B3. 综合分公式改为加性扣分制

```
final = 1.0 - sum(max(0, (1.0 - score_i) × weight_i) for i in dimensions)
```
（从满分 1.0 开始，各维度只根据其"扣分量"减分）

---

### 方案 C：引入跨维度联动（长期）

#### C1. 维度间条件依赖

- D4 自然度异常 → 应加重 D3 生物异常权重（运动不自然常伴随骨骼变形）
- D1 身份跳变 → 应加重 D7 时间一致性权重（身份突变是特殊的目标异常）
- D5 物理异常 → 应降低 D4 动态度中"正常运动"的容差

#### C2. 异常事件时空关联

当前每个维度独立检测异常帧索引。可引入：
- 同一帧序号的跨维度异常聚类 → 增强该帧的扣分权重
- 连续多帧同维度异常 → 视为持续事件，扣分加重（非简单累加）

## 五、快速验证方案

建议选 5 个正例 + 5 个负例，执行以下对照实验：

1. **Baseline**：当前 pipeline，记录各维度分 + 综合分
2. **A2 only**：仅修改 D3 扣分参数，其他不变，跑同一批视频
3. **A3.1 only**：仅修复 D4 smoothness 归一化，其他不变
4. **A2 + A3.1 + B1**：组合修复，跑同一批视频
5. 对比 4 组结果的 **Cohen's d 效应量**和正负例分数分布的重叠面积（OVL）

期望：组合修复后 OVL 从 > 60% 降至 < 30%，Cohen's d > 1.0。
