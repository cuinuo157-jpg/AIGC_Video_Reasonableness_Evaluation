针对您列举的这6个视频生成异常现象，结合 **VMBench** 和 **VBench-2.0** 的评测框架，我为您逐一分析检测方法：

## 现象归类与检测方案

### 1. 手指融合 + 手臂融合（变形类）

 **对应维度** ：VBench-2.0 **Human Anatomy（人体解剖学）** + VMBench **Temporal Consistency**

* **检测逻辑** ：VBench-2.0 使用专门的解剖学异常检测模型，识别肢体数量/拓扑结构的突变
* **技术实现** ：通过跨帧姿态估计（如 ViTPose）检测关键点数量变化，融合会导致关键点检测失败或数量异常

### 2. 舌头/残渣  **突兀消失** （消失类）

 **对应维度** ：VMBench **TCS（Temporal Consistency Score）** ⭐ 最匹配

* **检测逻辑** ：这正是 VMBench 设计 TCS 指标要解决的**典型问题**
* **判定流程** ：

1. GroundedSAM2 追踪舌头/残渣的掩码轨迹
2. CoTracker 验证运动连续性
3. **突兀消失判定** ：若物体在非遮挡、非出界情况下像素级突然缺失 → 标记为异常消失
4. 评分降低与异常帧定位

### 3. 多了肚脐/头发（突然出现类）

 **对应维度** ：VANE-Bench **Appearance** + VBench-2.0 **Object Emergence**

* **检测难点** ：现有基准对"突然出现"的检测弱于"消失"
* **可行方案** ：
* 双向验证：将视频倒序播放，用 VMBench 的消失检测逻辑检测"倒序消失"
* VLM 问答："肚脐在第一帧是否存在？"进行跨帧一致性校验

### 4. 少手指（肢体缺失类）

 **对应维度** ：VBench-2.0 **Human Anatomy** + VMBench **Object Persistence**

* **检测方法** ：解剖学维度会标记"手指数量不一致"为异常，结合 TCS 追踪手掌 ROI 区域像素变化

## 推荐检测策略

针对您这6个现象，建议采用  **分层检测** ：

**表格**

| 异常类型                            | 推荐基准                       | 具体操作                                           |
| :---------------------------------- | :----------------------------- | :------------------------------------------------- |
| **突兀消失** （舌头、残渣）   | **VMBench-TCS**          | 运行轨迹验证，查看 `abrupt_disappearance` 标记帧 |
| **融合/变形** （手指、手臂）  | **VBench-2.0-Anatomy**   | 检查解剖学一致性分数，关注 topology error          |
| **非自然出现** （肚脐、头发） | **VANE-Bench**           | 使用 QA 模式询问物体存在性时序                     |
| **肢体缺失** （少手指）       | **VMBench + VBench-2.0** | 结合关键点检测与像素追踪                           |

## 关键发现

您观察到的  **"突兀消失"** （现象1、6）正是 **VMBench 在2025年1月论文中重点指出的 Sora 典型缺陷**

。VMBench 的实验显示，当前视频模型在 **细粒度物体（如嘴部残渣、舌头）的时序保持** 上失败率极高，而 VMBench 的 TCS 指标相比传统 CLIP 相似度，对这类异常的人体感知对齐度提升了  **32.7%** 。
