# 技术选型记录

## 初始选型 (2026-03-09)

| 决策项 | 选择 | 理由 |
|--------|------|------|
| Python 版本 | 3.10+ | match 语法, 类型注解增强 |
| 测试框架 | Pytest | 简洁, 插件丰富 |
| 代码检查 | Ruff | 速度快, 兼容 flake8/isort |
| 深度学习框架 | PyTorch | 生态成熟, 模型兼容性好 |
| 光流估计 | RAFT | 精度与速度平衡 |
| 目标跟踪 | CoTracker / SAM2 | 点跟踪 + 分割能力 |
| 视频质量评估 | Q-Align | 多模态质量感知 |
