# perceptual_quality 算法分析报告

## 一、算法用途

### 1.1 核心功能

`perceptual_quality` 是一个**视频感知质量评估模块**，主要用于：

1. **视频模糊检测**：检测视频中的模糊异常帧
2. **质量评分**：基于 Q-Align 模型计算视频质量分数
3. **异常帧定位**：精确定位质量下降的帧位置
4. **严重程度评估**：评估模糊的严重程度（轻微/中等/严重）
5. **辅助视频质量评估**：作为视频合理性评估的辅助指标

### 1.2 应用场景

- **AIGC视频质量评估**：评估AI生成视频的感知质量
- **视频模糊检测**：检测视频中的模糊、抖动等质量问题
- **视频质量监控**：批量检测视频质量，筛选低质量视频
- **视频修复指导**：定位需要修复的帧，提供修复建议
- **视频预处理**：在视频处理流程中自动检测质量问题

## 二、可识别的视频外部表现异常

### 2.1 感知质量异常类型

算法可以识别以下视频外部表现异常：

#### 1. **模糊异常**
- **表现**：视频帧出现模糊、失焦
- **检测指标**：
  - 质量分数突然下降（`max_quality_drop > threshold`）
  - 模糊帧比例过高（`blur_ratio > 0.05`）
  - 平均质量分数过低（`avg_quality` 异常低）

#### 2. **质量不稳定异常**
- **表现**：视频质量在时间上不稳定，忽高忽低
- **检测指标**：
  - 质量分数标准差过大（`quality_std` 异常高）
  - 相邻帧质量差异过大（`quality_diffs` 超过阈值）

#### 3. **局部模糊异常**
- **表现**：视频中部分帧出现模糊，其他帧正常
- **检测指标**：
  - 模糊帧集中分布（`blur_frames` 集中）
  - 质量分数出现局部下降

#### 4. **整体质量下降异常**
- **表现**：整个视频质量持续偏低
- **检测指标**：
  - 平均质量分数持续偏低（`avg_quality < 0.5`）
  - 模糊帧比例高（`blur_ratio > 0.3`）

#### 5. **相机运动导致的模糊**
- **表现**：相机运动导致的画面模糊
- **检测指标**：
  - 相机运动幅度高（`camera_movement > 0.5`）
  - 自适应阈值提高但仍检测到模糊

#### 6. **帧间质量跳跃异常**
- **表现**：相邻帧之间质量差异过大
- **检测指标**：
  - 质量分数差值超过阈值（`score_differences > threshold`）
  - 检测到多个异常帧对

### 2.2 具体异常表现示例

| 异常类型 | 视频外部表现 | 可能原因 |
|---------|------------|---------|
| **运动模糊** | 快速运动物体出现拖尾 | 快门速度过慢、帧率不足 |
| **失焦模糊** | 画面整体或局部失焦 | 对焦失败、景深过浅 |
| **抖动模糊** | 画面不稳定晃动 | 手持拍摄、相机不稳定 |
| **压缩模糊** | 画面出现块状模糊 | 视频压缩过度、码率过低 |
| **生成模糊** | AI生成视频质量下降 | 生成模型不稳定、后处理错误 |
| **局部模糊** | 部分区域模糊 | 镜头污渍、局部对焦失败 |

## 三、算法解决思路

### 3.1 整体架构

```
视频文件
    ↓
滑动窗口加载帧组
    ↓
Q-Align 模型质量评分
    ↓
相机运动幅度估算
    ↓
自适应阈值计算
    ↓
异常帧检测
    ↓
模糊指标计算
    ↓
严重程度判定
    ↓
检测结果生成
```

### 3.2 核心解决思路

#### 思路1：基于 Q-Align 的质量评分

**原理**：
- 使用 Q-Align 多模态大模型评估视频质量
- Q-Align 能够理解视频的感知质量，给出质量等级评分
- 质量等级：excellent (1.0) > good (0.75) > fair (0.5) > poor (0.25) > bad (0.0)

**实现**：
- 使用滑动窗口方式加载视频帧组（默认窗口大小 3 帧）
- 将帧组输入 Q-Align 模型进行质量评估
- 模型输出各质量等级的概率分布
- 加权计算得到质量分数：`weighted_score = probabilities @ quality_weights`

#### 思路2：滑动窗口时序分析

**原理**：
- 为每帧配备邻域帧组，利用时序信息提高检测准确性
- 窗口大小可配置（默认 3 帧）

**实现**：
- 对每帧，加载前后各 `(window_size-1)//2` 帧
- 边界帧通过复制补齐窗口
- 将帧组作为整体输入模型评估

#### 思路3：相机运动自适应阈值

**原理**：
- 相机运动会导致画面整体变化，需要调整检测阈值
- 运动幅度越大，允许的质量变化越大

**实现**：
- 估算相机运动幅度：计算相邻帧的像素差异
- 根据运动幅度自适应调整阈值：
  ```
  if camera_movement < 0.1:
      threshold = 0.01
  elif 0.1 <= camera_movement < 0.3:
      threshold = 0.015
  elif 0.3 <= camera_movement < 0.5:
      threshold = 0.025
  else:
      threshold = 0.03
  ```

#### 思路4：异常帧检测算法

**原理**：
- 通过检测质量分数的突然变化来定位异常帧
- 相邻帧质量差异超过阈值即为异常

**实现**：
```python
# 计算相邻帧质量分数差值
score_differences = abs(diff(quality_scores))

# 找到差值超过阈值的位置
artifact_indices = where(score_differences > threshold)

# 返回异常帧索引（包括当前帧和下一帧）
artifact_frames = unique([artifact_indices, artifact_indices + 1])
```

#### 思路5：模糊严重程度分级

**原理**：
- 根据模糊帧比例和质量下降幅度判定严重程度
- 分为：无模糊、轻微模糊、中等模糊、严重模糊

**实现**：
```python
if blur_ratio > 0.3 or max_quality_drop > threshold * 2:
    severity = "严重模糊"
elif blur_ratio > 0.1 or max_quality_drop > threshold * 1.5:
    severity = "中等模糊"
elif blur_ratio > 0.05 or max_quality_drop > threshold:
    severity = "轻微模糊"
else:
    severity = "无模糊"
```

#### 思路6：综合置信度计算

**原理**：
- 综合多个指标计算检测置信度
- 模糊比例、质量下降、平均质量共同决定置信度

**实现**：
```python
blur_confidence = min(1.0, blur_ratio * 2.0)  # 模糊比例权重
quality_confidence = min(1.0, max_quality_drop * 10.0)  # 质量下降权重
avg_quality_confidence = max(0.0, 1.0 - avg_quality)  # 平均质量权重

confidence = (
    blur_confidence * 0.4 +
    quality_confidence * 0.4 +
    avg_quality_confidence * 0.2
)
```

#### 思路7：批处理优化

**原理**：
- 支持批处理以提高计算效率
- 可配置批处理大小以控制内存使用

**实现**：
- 将帧组分批输入模型
- 每批处理完成后释放 GPU 显存
- 合并各批次结果

## 四、指标和判定标准

### 4.1 核心指标

#### 1. **质量分数（Quality Score）**

**定义**：Q-Align 模型评估的视频质量分数，范围 [0, 1]

**计算**：
```
quality_score = probabilities @ quality_weights
其中 quality_weights = [1.0, 0.75, 0.5, 0.25, 0.0]
对应质量等级：excellent, good, fair, poor, bad
```

**判定标准**：

| 质量分数范围 | 等级 | 描述 |
|-----------|------|------|
| [0.9, 1.0] | 优秀 | 视频质量极佳 |
| [0.75, 0.9) | 良好 | 视频质量良好 |
| [0.5, 0.75) | 一般 | 视频质量一般 |
| [0.25, 0.5) | 较差 | 视频质量较差 |
| [0, 0.25) | 很差 | 视频质量很差 |

#### 2. **模糊帧比例（Blur Ratio）**

**定义**：模糊帧占总帧数的比例

**计算**：
```
blur_ratio = blur_frame_count / total_frames
```

**判定标准**：
- **无模糊**：< 0.05
- **轻微模糊**：0.05 ~ 0.1
- **中等模糊**：0.1 ~ 0.3
- **严重模糊**：> 0.3

#### 3. **最大质量下降（Max Quality Drop）**

**定义**：相邻帧之间质量分数的最大差值

**计算**：
```
quality_diffs = abs(diff(quality_scores))
max_quality_drop = max(quality_diffs)
```

**判定标准**：
- **正常**：< threshold（自适应阈值）
- **轻微异常**：threshold ~ threshold * 1.5
- **中等异常**：threshold * 1.5 ~ threshold * 2
- **严重异常**：> threshold * 2

#### 4. **自适应阈值（Adaptive Threshold）**

**定义**：根据相机运动幅度动态调整的检测阈值

**计算**：
```
if camera_movement < 0.1:
    threshold = 0.01
elif 0.1 <= camera_movement < 0.3:
    threshold = 0.015
elif 0.3 <= camera_movement < 0.5:
    threshold = 0.025
else:
    threshold = 0.03
```

**判定标准**：
- 相机运动幅度越大，阈值越高
- 阈值范围：0.01 ~ 0.03

#### 5. **平均质量分数（Average Quality）**

**定义**：所有帧质量分数的平均值

**计算**：
```
avg_quality = mean(quality_scores)
```

**判定标准**：
- **高质量**：> 0.75
- **中等质量**：0.5 ~ 0.75
- **低质量**：< 0.5

#### 6. **质量标准差（Quality Standard Deviation）**

**定义**：质量分数在时间上的变化程度

**计算**：
```
quality_std = std(quality_scores)
```

**判定标准**：
- **稳定**：< 0.05
- **中等稳定**：0.05 ~ 0.1
- **不稳定**：> 0.1（异常）

#### 7. **检测置信度（Confidence）**

**定义**：模糊检测结果的可信度

**计算**：
```
confidence = (
    blur_confidence * 0.4 +
    quality_confidence * 0.4 +
    avg_quality_confidence * 0.2
)
```

**判定标准**：
- **高置信度**：> 0.7
- **中等置信度**：0.4 ~ 0.7
- **低置信度**：< 0.4

### 4.2 模糊严重程度判定标准

#### 标准1：基于模糊比例和最大质量下降

**判定条件**：
```
IF blur_ratio > 0.3 OR max_quality_drop > threshold * 2:
    严重模糊
ELIF blur_ratio > 0.1 OR max_quality_drop > threshold * 1.5:
    中等模糊
ELIF blur_ratio > 0.05 OR max_quality_drop > threshold:
    轻微模糊
ELSE:
    无模糊
```

#### 标准2：模糊检测判定

**判定条件**：
```
blur_detected = (
    blur_ratio > BLUR_RATIO_THRESHOLD (0.05) OR
    max_quality_drop > threshold
)
```

### 4.3 异常判定标准

#### 标准1：质量突然下降

**判定条件**：
```
IF max_quality_drop > threshold:
    异常：质量突然下降
```

#### 标准2：模糊帧比例过高

**判定条件**：
```
IF blur_ratio > 0.05:
    异常：模糊帧比例过高
```

#### 标准3：整体质量偏低

**判定条件**：
```
IF avg_quality < 0.5:
    异常：整体质量偏低
```

#### 标准4：质量不稳定

**判定条件**：
```
IF quality_std > 0.1:
    异常：质量在时间上不稳定
```

#### 标准5：质量分数异常低

**判定条件**：
```
IF avg_quality < 0.25:
    异常：质量分数异常低（可能严重模糊）
```

### 4.4 综合异常评分

**异常严重程度分级**：

| 严重程度 | 判定条件 | 处理建议 |
|---------|---------|---------|
| **严重异常** | 模糊比例 > 0.3 或质量下降 > 2*threshold | 视频质量不合格，建议重新生成 |
| **中等异常** | 模糊比例 0.1~0.3 或质量下降 1.5~2*threshold | 需要人工审核，可考虑修复 |
| **轻微异常** | 模糊比例 0.05~0.1 或质量下降 threshold~1.5*threshold | 可接受但需注意 |
| **正常** | 模糊比例 < 0.05 且质量下降 < threshold | 视频质量合格 |

**异常评分计算**（示例）：
```python
anomaly_score = 0.0
if blur_ratio > 0.3:
    anomaly_score += 0.4
elif blur_ratio > 0.1:
    anomaly_score += 0.25
elif blur_ratio > 0.05:
    anomaly_score += 0.15

if max_quality_drop > threshold * 2:
    anomaly_score += 0.3
elif max_quality_drop > threshold * 1.5:
    anomaly_score += 0.2
elif max_quality_drop > threshold:
    anomaly_score += 0.1

if avg_quality < 0.25:
    anomaly_score += 0.3
elif avg_quality < 0.5:
    anomaly_score += 0.15

if anomaly_score > 0.6:
    status = "严重异常"
elif anomaly_score > 0.4:
    status = "中等异常"
elif anomaly_score > 0.2:
    status = "轻微异常"
else:
    status = "正常"
```

## 五、算法优势与局限

### 5.1 优势

1. **基于大模型评估**：使用 Q-Align 多模态大模型，能够理解视频的感知质量
2. **自适应阈值**：根据相机运动自动调整检测阈值，提高准确性
3. **精确定位**：能够精确定位模糊帧的位置
4. **严重程度分级**：提供模糊严重程度的详细分级
5. **批处理支持**：支持批量检测，提高处理效率
6. **可解释性强**：提供详细的质量分数、模糊帧位置等信息

### 5.2 局限

1. **依赖模型质量**：Q-Align 模型的准确性直接影响检测结果
2. **计算复杂度**：大模型推理较慢，处理长视频耗时较长
3. **内存占用**：批处理需要较大 GPU 显存
4. **阈值敏感性**：自适应阈值可能对某些场景不够准确
5. **无法区分模糊类型**：无法区分运动模糊、失焦模糊等不同类型
6. **对特定异常不敏感**：如色彩异常、纹理崩坏等

## 六、使用建议

### 6.1 参数调优

- **窗口大小**：`window_size = 3`（默认），可调整为 2（快速）或 5（准确）
- **批处理大小**：`batch_size = 32`（默认），根据 GPU 显存调整
- **模糊阈值**：
  - 轻微模糊：0.015
  - 中等模糊：0.025
  - 严重模糊：0.04

### 6.2 异常检测流程

1. **加载视频并计算质量分数**
2. **估算相机运动幅度**
3. **计算自适应阈值**
4. **检测异常帧**
5. **计算模糊指标**
6. **判定模糊严重程度**
7. **生成检测结果和建议**

### 6.3 结果解读

- **blur_detected**：是否检测到模糊（主要指标）
- **blur_severity**：模糊严重程度（轻微/中等/严重）
- **blur_ratio**：模糊帧比例，反映模糊范围
- **max_quality_drop**：最大质量下降，反映模糊强度
- **avg_quality**：平均质量分数，反映整体质量
- **confidence**：检测置信度，低置信度需要谨慎解读
- **blur_frames**：模糊帧索引列表，用于定位问题帧

## 八、总结

`perceptual_quality` 算法通过 Q-Align 大模型质量评分、滑动窗口时序分析、自适应阈值、异常帧检测等技术，能够有效检测视频中的模糊异常，精确定位问题帧，并提供模糊严重程度评估。算法设计合理，指标明确，适用于AIGC视频质量评估和异常检测场景。

算法特别适合检测：
- 运动模糊
- 失焦模糊
- 抖动模糊
- 质量突然下降
- 整体质量偏低

对于需要区分模糊类型或检测其他感知质量问题的场景，可能需要结合其他检测方法。
