# aux_motion_intensity（第一版）主体和背景动态度说明

## 问题：输出结果是否包含主体和背景区域的动态程度？

### 答案：**不包含**

`aux_motion_intensity`（第一版）的输出结果**不包含明确的主体和背景区域的动态程度**。

---

## 详细说明

### 1. 区域划分方式

`aux_motion_intensity`（第一版）使用的是**静态区域/动态区域**划分，而不是**主体/背景**划分：

#### 静态区域（Static Regions）
- **检测方法**：基于光流幅值自动检测
- **判断标准**：`flow_magnitude < threshold`
  - 未归一化：`flow_threshold = 2.0`
  - 归一化：`flow_threshold_ratio = 0.002`
- **计算指标**：
  - `static_dynamics['dynamics_score']`：静态区域的动态分数
  - `static_dynamics['mean_magnitude']`：静态区域的平均光流幅值

#### 动态区域（Dynamic Regions）
- **检测方法**：非静态区域即为动态区域（`~static_mask`）
- **计算指标**：
  - `global_dynamics['mean_dynamic_magnitude']`：动态区域的平均光流幅值
  - `global_dynamics['dynamic_ratio']`：动态区域占比

### 2. 输出结果中的相关信息

从实际输出结果来看：

```json
{
  "motion_intensity": 0.277,
  "scene_type": "static",
  "temporal_stats": {
    "mean_dynamics_score": 0.973,        // 静态区域的动态分数（平均）
    "mean_static_ratio": 0.663,          // 静态区域占比
    "mean_consistency_score": 0.148,      // 空间一致性分数
    "temporal_stability": 0.867           // 时序稳定性
    // 注意：虽然代码中计算了 mean_dynamic_magnitude，
    // 但在最终输出中可能没有完整展示
  }
}
```

### 3. 代码中的计算逻辑

虽然代码中确实计算了动态区域的相关指标（`static_dynamics.py` 第186-189行）：

```python
'mean_dynamic_magnitude': float(np.mean(mean_dynamic_magnitudes)),
'std_dynamic_magnitude': float(np.std(mean_dynamic_magnitudes)),
'max_dynamic_magnitude': float(np.max(mean_dynamic_magnitudes)),
'min_dynamic_magnitude': float(np.min(mean_dynamic_magnitudes)),
```

但这些信息可能：
1. 在 `temporal_stats` 中计算但未在最终输出中展示
2. 或者需要通过访问 `frame_results` 才能获取每帧的详细信息

### 4. 与 aux_motion_intensity_2 的对比

| 特性 | aux_motion_intensity（第一版） | aux_motion_intensity_2（第二版） |
|------|------------------------------|--------------------------------|
| **区域划分** | 静态区域 / 动态区域 | 主体区域 / 背景区域 |
| **检测方法** | 基于光流幅值自动检测 | 基于 Grounded-SAM-2 语义分割 |
| **主体动态度** | ❌ 不包含 | ✅ `subject_motion` |
| **背景动态度** | ❌ 不包含 | ✅ `background_motion` |
| **纯主体动态度** | ❌ 不包含 | ✅ `pure_subject_motion` |
| **运动比率** | ❌ 不包含 | ✅ `motion_ratio` |
| **静态区域动态度** | ✅ `mean_dynamics_score` | - |
| **动态区域动态度** | ⚠️ 计算但可能未完整输出 | - |

---

## 总结

1. **aux_motion_intensity（第一版）不包含主体和背景区域的动态程度**
2. 它提供的是**静态区域和动态区域**的动态程度
3. 静态区域 ≠ 背景区域，动态区域 ≠ 主体区域
4. 如果需要主体/背景分离的动态度，应使用 **aux_motion_intensity_2（第二版）**
