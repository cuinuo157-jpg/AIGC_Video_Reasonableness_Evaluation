# 动态场景判定和动态区域阈值设定总结

## 一、动态场景判定阈值

### 1.1 aux_motion_intensity（第一版）

**文件位置**：`src/aux_motion_intensity/unified_dynamics_scorer.py`

**核心阈值**：
- **阈值名称**：`static_ratio`
- **默认值**：`0.5`
- **代码位置**：第32行（归一化模式）或第40行（未归一化模式）

**判定规则**：
```python
if camera_comp_enabled and mean_static_ratio > 0.5:
    return 'static'  # 静态场景
else:
    return 'dynamic'  # 动态场景
```

**关键条件**：
- 必须启用相机补偿（`camera_comp_enabled == True`）
- 如果未启用相机补偿，无论 `mean_static_ratio` 是多少，都判定为 `'dynamic'`

**判定指标**：
- `mean_static_ratio`：平均静态区域比例（取值范围 [0, 1]）
  - `> 0.5`：静态场景（静态区域占比超过50%）
  - `<= 0.5`：动态场景（静态区域占比小于等于50%）

---

### 1.2 aux_motion_intensity_2（第二版）

**文件位置**：`src/aux_motion_intensity_2/scene_classifier.py`

**核心阈值**：
- **阈值名称**：`static_threshold`
- **默认值**：`0.1`
- **代码位置**：第14行

**判定规则**：
```python
if pure_subject_motion < 0.1:
    return 'static'  # 静态场景
else:
    return 'dynamic'  # 动态场景
```

**判定指标**：
- `pure_subject_motion`：纯主体动态度（主体动态度 - 背景动态度）
  - `< 0.1`：静态场景
  - `>= 0.1`：动态场景

**运动强度等级阈值**（基于 `pure_subject_motion`）：
- **static（静态）**: < 0.1
- **low_dynamic（低动态）**: 0.1 ~ 0.3
- **medium_dynamic（中等动态）**: 0.3 ~ 0.6
- **high_dynamic（高动态）**: 0.6 ~ 1.0
- **extreme_dynamic（极高动态）**: >= 1.0

**运动主导类型判断阈值**（基于 `motion_ratio = pure_subject_motion / background_motion`）：
- **阈值名称**：`motion_ratio_threshold`
- **默认值**：`1.5`
- **代码位置**：第18行
- **判定规则**：
  - `motion_ratio < 1.5` → `camera_motion`（相机运动主导）
  - `motion_ratio >= 1.5` → `object_motion`（物体运动主导）

## 二、动态区域阈值

### 2.1 静态/动态区域检测阈值

**文件位置**：`src/aux_motion_intensity/static_dynamics.py`

**类名**：`StaticObjectDetector`

**核心阈值**：

#### 2.1.1 未归一化模式
- **阈值名称**：`flow_threshold`
- **默认值**：`2.0`
- **代码位置**：第15行
- **判定规则**：
  ```python
  flow_magnitude = sqrt(flow_x^2 + flow_y^2)
  static_mask = flow_magnitude < 2.0  # 静态区域
  dynamic_mask = ~static_mask  # 动态区域（非静态区域）
  ```

#### 2.1.2 归一化模式
- **阈值名称**：`flow_threshold_ratio`
- **默认值**：`0.002`
- **代码位置**：第16行
- **判定规则**：
  ```python
  diagonal = sqrt(h^2 + w^2)
  flow_magnitude_normalized = flow_magnitude / diagonal
  static_mask = flow_magnitude_normalized < 0.002  # 静态区域
  dynamic_mask = ~static_mask  # 动态区域（非静态区域）
  ```

**说明**：
- 静态区域：光流幅值小于阈值的区域
- 动态区域：光流幅值大于等于阈值的区域（即非静态区域）

---

### 2.2 其他相关阈值

#### 2.2.1 最小区域大小
- **阈值名称**：`min_region_size`
- **默认值**：`100`（像素）
- **代码位置**：`static_dynamics.py` 第19行
- **作用**：过滤掉小于100像素的静态区域（去除噪声）

#### 2.2.2 动态阈值
- **阈值名称**：`dynamics_threshold`
- **默认值**：`1.0`
- **代码位置**：`static_dynamics.py` 第79行
- **说明**：用于计算静态区域的动态分数

#### 2.2.3 静态区域细化阈值
- **严格静态区域阈值**：`flow_threshold * 0.5` 或 `flow_threshold_ratio * 0.5`
- **代码位置**：`static_dynamics.py` 第61行（归一化）或第63行（未归一化）
- **作用**：在边缘区域使用更严格的阈值来细化静态区域检测

#### 2.2.4 一致性阈值
- **阈值名称**：`consistency_threshold`
- **默认值**：`0.8`
- **代码位置**：`static_dynamics.py` 第18行
- **说明**：用于静态区域的一致性判断

## 五、使用示例

### 5.1 第一版：动态场景判定

```python
# 阈值设定
thresholds = {
    'static_ratio': 0.5  # 动态场景判定阈值
}

# 判定逻辑
mean_static_ratio = 0.663  # 从 temporal_stats 获取
camera_comp_enabled = True

if camera_comp_enabled and mean_static_ratio > 0.5:
    scene_type = 'static'  # 静态场景
else:
    scene_type = 'dynamic'  # 动态场景
```

### 5.2 第二版：动态场景判定

```python
# 阈值设定
static_threshold = 0.1  # 静态场景阈值
motion_ratio_threshold = 1.5  # 运动比率阈值

# 判定逻辑
pure_subject_motion = 0.444
motion_ratio = 2.891

if pure_subject_motion < 0.1:
    scene_type = 'static'
else:
    scene_type = 'dynamic'

if motion_ratio >= 1.5:
    motion_dominant = 'object_motion'  # 物体运动主导
else:
    motion_dominant = 'camera_motion'  # 相机运动主导
```

### 5.3 动态区域检测

```python
# 阈值设定（归一化模式）
flow_threshold_ratio = 0.002
min_region_size = 100

# 检测逻辑
flow_magnitude = sqrt(flow_x^2 + flow_y^2)
diagonal = sqrt(h^2 + w^2)

static_mask = flow_magnitude_normalized < 0.002
dynamic_mask = ~static_mask  # 动态区域
```

## 六、注意事项

1. **相机补偿的重要性**：
   - 第一版必须在 `camera_comp_enabled == True` 时，场景类型判定才有效
   - 未启用相机补偿时，无论 `mean_static_ratio` 是多少，都判定为 `'dynamic'`

2. **归一化 vs 未归一化**：
   - 归一化模式使用 `flow_threshold_ratio = 0.002`，适用于不同分辨率的视频
   - 未归一化模式使用 `flow_threshold = 2.0`，适用于固定分辨率的视频

3. **动态区域的定义**：
   - 动态区域 = 非静态区域（`~static_mask`）
   - 静态区域通过光流幅值阈值自动检测，不是基于语义分割

4. **阈值调整建议**：
   - 提高 `static_ratio`（如 0.6）：更严格，只有静态区域占比很高才判定为静态
   - 降低 `static_ratio`（如 0.4）：更宽松，静态区域占比稍高就判定为静态
   - 调整 `flow_threshold_ratio`：影响静态/动态区域的划分，进而影响 `mean_static_ratio`
