# aux_motion_intensity 动态属性评估阈值分析报告

## 一、阈值概览

### 1.1 aux_motion_intensity（第一版）阈值设置

#### 场景类型判断阈值
- **静态/动态场景判断**：
  - 判断依据：`mean_static_ratio > 0.5` → 静态场景
  - 阈值位置：`unified_dynamics_scorer.py` 第72行
  - 说明：当静态区域比例超过50%时，判定为静态场景

#### 动态强度分类阈值（DynamicsClassifier）
基于 `unified_dynamics_score` 进行分类：
- **pure_static（纯静态）**: < 0.15
- **low_dynamic（低动态）**: 0.15 ~ 0.35
- **medium_dynamic（中等动态）**: 0.35 ~ 0.65
- **high_dynamic（高动态）**: 0.65 ~ 0.85
- **extreme_dynamic（极高动态）**: >= 0.85

#### 其他内部阈值
- `flow_low`: 1.0（未归一化）或 1.0/baseline_diagonal（归一化）
- `flow_mid`: 5.0（未归一化）或 5.0/baseline_diagonal（归一化）
- `flow_high`: 15.0（未归一化）或 15.0/baseline_diagonal（归一化）
- `temporal_std`: 1.0（未归一化）或 1.0/baseline_diagonal（归一化）

### 1.2 aux_motion_intensity_2（第二版）阈值设置

#### 场景分类器阈值（SceneClassifier）

**运动强度等级阈值**（基于 `pure_subject_motion`）：
- **static（静态）**: < 0.1
- **low_dynamic（低动态）**: 0.1 ~ 0.3
- **medium_dynamic（中等动态）**: 0.3 ~ 0.6
- **high_dynamic（高动态）**: 0.6 ~ 1.0
- **extreme_dynamic（极高动态）**: >= 1.0

**运动主导类型判断阈值**（基于 `motion_ratio = pure_subject_motion / background_motion`）：
- **camera_motion（相机运动主导）**: `motion_ratio < 1.5`
- **object_motion（物体运动主导）**: `motion_ratio >= 1.5`
- **mixed_motion（混合运动）**: 其他情况

**置信度计算阈值**：
- 运动比率极端情况（高置信度）：`motion_ratio < 0.5` 或 `motion_ratio > 2.0` → 置信度 0.9
- 运动比率接近（低置信度）：`0.8 < motion_ratio < 1.2` → 置信度 0.3
- 其他情况：置信度 0.6
- 总运动量合理范围：`0.01 < total_motion < 5.0` → 强度置信度 0.8

## 二、主体和背景动态度阈值

### 2.1 主体和背景动态度计算

**主体动态度（subject_motion）**：
- 通过 CoTracker 在主体掩码区域内跟踪计算
- 可选的归一化：按主体对角线归一化（`normalize_by_subject_diag=True`）

**背景动态度（background_motion）**：
- 通过 CoTracker 在背景区域（非主体区域）跟踪计算

**纯主体动态度（pure_subject_motion）**：
- 计算公式：`max(0, subject_motion - background_motion)`
- 用于去除相机运动的影响

**运动比率（motion_ratio）**：
- 计算公式：`pure_subject_motion / (background_motion + 1e-8)`
- 用于判断运动主导类型

### 2.2 主体和背景动态度阈值

**aux_motion_intensity_2 中的阈值**：
- **运动比率阈值**: 1.5
  - `motion_ratio < 1.5` → 相机运动主导
  - `motion_ratio >= 1.5` → 物体运动主导

**aux_motion_intensity 中的阈值**：
- 没有明确的主体/背景动态度阈值
- 主要通过 `mean_static_ratio` 和 `unified_dynamics_score` 进行综合判断

## 五、关键结论

### 5.1 动态/静态场景阈值

1. **aux_motion_intensity**：
   - 静态场景：`mean_static_ratio > 0.5`
   - 动态场景：`mean_static_ratio <= 0.5`

2. **aux_motion_intensity_2**：
   - 静态场景：`pure_subject_motion < 0.1`
   - 动态场景：`pure_subject_motion >= 0.1`

### 5.2 主体和背景动态度阈值

1. **运动比率阈值**：1.5
   - 用于区分相机运动主导（< 1.5）和物体运动主导（>= 1.5）

2. **主体和背景动态度本身没有绝对阈值**
   - 主要通过相对比较（运动比率）来判断运动类型
   - 纯主体动态度用于判断强度等级

### 5.3 输出结果解读建议

1. **查看 `scene_type`**：快速了解场景类型
2. **查看 `motion_intensity` 或 `pure_subject_motion`**：了解运动强度
3. **查看 `motion_ratio`**：判断是相机运动还是物体运动
4. **查看 `mean_static_ratio`**：了解静态区域占比
5. **查看 `confidence`**：评估分类结果的可信度

## 六、重要说明：主体/背景 vs 静态/动态区域

### 6.1 aux_motion_intensity（第一版）的区域划分方式

**重要区别**：
- **aux_motion_intensity（第一版）不包含明确的主体和背景区域的动态程度**
- 它区分的是**静态区域**和**动态区域**，而不是主体和背景

**区域划分逻辑**：
1. **静态区域（Static Regions）**：
   - 通过光流幅值检测：`flow_magnitude < threshold`
   - 阈值：`flow_threshold = 2.0`（未归一化）或 `flow_threshold_ratio = 0.002`（归一化）
   - 计算静态区域的动态程度：`static_dynamics['dynamics_score']`

2. **动态区域（Dynamic Regions）**：
   - 非静态区域即为动态区域：`~static_mask`
   - 计算动态区域的平均光流幅值：`mean_dynamic_magnitude`

**输出中包含的信息**：
- `temporal_stats['mean_dynamics_score']`：静态区域的动态分数（平均）
- `temporal_stats['mean_static_ratio']`：静态区域占比
- `temporal_stats['mean_dynamic_magnitude']`：动态区域的平均光流幅值（代码中计算，但可能未完整输出）

**注意**：
- 静态区域 ≠ 背景区域
- 动态区域 ≠ 主体区域
- 这种划分是基于光流幅值的自动检测，不是基于语义分割的主体/背景识别

### 6.2 aux_motion_intensity_2（第二版）的区域划分方式

**明确区分主体和背景**：
- 使用 Grounded-SAM-2 进行主体检测和分割
- 计算**主体动态度（subject_motion）**和**背景动态度（background_motion）**
- 计算**纯主体动态度（pure_subject_motion = subject_motion - background_motion）**
- 计算**运动比率（motion_ratio = pure_subject_motion / background_motion）**

**输出中包含的信息**：
- `background_motion`：背景动态度
- `subject_motion`：主体动态度
- `pure_subject_motion`：纯主体动态度
- `motion_ratio`：运动比率
