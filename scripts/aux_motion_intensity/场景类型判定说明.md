# 动态属性场景类型判定说明

## 一、判定流程

场景类型判定在 `UnifiedDynamicsScorer._detect_scene_type()` 方法中实现。

### 1.1 判定逻辑

```python
def _detect_scene_type(self, temporal_stats: Dict, camera_comp_enabled: bool) -> str:
    # 1. 如果模式强制指定，直接返回
    if self.mode == 'static_scene':
        return 'static'
    if self.mode == 'dynamic_scene':
        return 'dynamic'
    
    # 2. 自动判定（mode == 'auto'）
    mean_static_ratio = temporal_stats['mean_static_ratio']
    if camera_comp_enabled and mean_static_ratio > self.thresholds['static_ratio']:
        return 'static'
    return 'dynamic'
```

### 1.2 判定流程图

```
开始
  ↓
检查 mode 参数
  ↓
┌─────────────────┐
│ mode == 'static_scene'? │ → 是 → 返回 'static'
└─────────────────┘
  ↓ 否
┌─────────────────┐
│ mode == 'dynamic_scene'? │ → 是 → 返回 'dynamic'
└─────────────────┘
  ↓ 否 (mode == 'auto')
获取 mean_static_ratio
  ↓
┌─────────────────────────────┐
│ camera_comp_enabled == True │
│ AND                         │ → 是 → 继续判断
│ mean_static_ratio > 0.5?    │
└─────────────────────────────┘
  ↓ 是
返回 'static'
  ↓ 否
返回 'dynamic'
```

## 二、关键指标（变量名）

### 2.1 主要判定指标

#### **mean_static_ratio**（核心指标）

**变量位置**：`temporal_stats['mean_static_ratio']`

**定义**：平均静态区域比例，表示视频中静态区域占整个画面的平均比例

**计算过程**：

1. **单帧静态区域检测**（`StaticObjectDetector.detect_static_regions()`）：
   ```python
   # 计算光流幅值
   flow_magnitude = sqrt(flow[:, :, 0]^2 + flow[:, :, 1]^2)
   
   # 归一化（如果启用）
   if use_normalized_flow:
       diagonal = sqrt(h^2 + w^2)
       flow_magnitude = flow_magnitude / diagonal
       threshold = flow_threshold_ratio  # 默认 0.002
   else:
       threshold = flow_threshold  # 默认 2.0
   
   # 检测静态区域（光流幅值小于阈值）
   static_mask = flow_magnitude < threshold
   ```

2. **单帧静态比例计算**（`StaticObjectDynamicsCalculator.calculate_global_dynamics()`）：
   ```python
   total_pixels = h * w
   static_pixels = sum(static_mask)
   static_ratio = static_pixels / total_pixels  # 单帧静态比例
   ```

3. **时序平均**（`StaticObjectDynamicsCalculator.calculate_temporal_statistics()`）：
   ```python
   static_ratios = [r['global_dynamics']['static_ratio'] for r in frame_results]
   mean_static_ratio = mean(static_ratios)  # 所有帧的平均静态比例
   ```

**取值范围**：[0, 1]
- `0`：完全没有静态区域（全部动态）
- `1`：完全静态（没有动态区域）
- `0.5`：静态和动态区域各占一半

### 2.2 辅助判定条件

#### **camera_comp_enabled**（布尔值）

**变量位置**：`_detect_scene_type()` 方法参数

**定义**：是否启用了相机运动补偿

**作用**：
- 如果 `camera_comp_enabled == False`，无论 `mean_static_ratio` 是多少，都返回 `'dynamic'`
- 只有 `camera_comp_enabled == True` 时，才会根据 `mean_static_ratio` 判定场景类型

**原因**：
- 相机运动补偿能够去除相机运动的影响，得到真实的物体运动
- 未启用相机补偿时，相机运动会被误判为物体运动，导致静态场景被误判为动态场景

#### **mode**（字符串）

**变量位置**：`UnifiedDynamicsScorer.mode`

**定义**：场景类型判定模式

**可选值**：
- `'auto'`：自动判定（默认）
- `'static_scene'`：强制判定为静态场景
- `'dynamic_scene'`：强制判定为动态场景

**作用**：
- 如果 `mode != 'auto'`，直接返回对应的场景类型，不进行自动判定

## 三、判定阈值

### 3.1 核心阈值

#### **static_ratio 阈值**

**变量名**：`self.thresholds['static_ratio']`

**默认值**：`0.5`

**位置**：`UnifiedDynamicsScorer.__init__()` 中的 `default_thresholds`

**判定规则**：
```python
if mean_static_ratio > 0.5:
    判定为 'static'（静态场景）
else:
    判定为 'dynamic'（动态场景）
```

**含义**：
- 当静态区域占比超过 50% 时，判定为静态场景
- 当静态区域占比小于等于 50% 时，判定为动态场景

### 3.2 相关阈值

#### **flow_threshold_ratio**（静态区域检测阈值 - 归一化）

**变量名**：`StaticObjectDetector.flow_threshold_ratio`

**默认值**：`0.002`

**位置**：`StaticObjectDetector.__init__()`

**作用**：用于检测单帧中的静态区域（归一化光流）

**计算**：
```python
if use_normalized_flow:
    flow_magnitude_normalized = flow_magnitude / diagonal
    static_mask = flow_magnitude_normalized < 0.002
```

#### **flow_threshold**（静态区域检测阈值 - 未归一化）

**变量名**：`StaticObjectDetector.flow_threshold`

**默认值**：`2.0`

**位置**：`StaticObjectDetector.__init__()`

**作用**：用于检测单帧中的静态区域（未归一化光流）

**计算**：
```python
if not use_normalized_flow:
    static_mask = flow_magnitude < 2.0
```

## 四、完整判定示例

### 4.1 示例1：静态场景判定

**输入数据**：
```python
temporal_stats = {
    'mean_static_ratio': 0.663,  # 静态区域占比 66.3%
    ...
}
camera_comp_enabled = True
mode = 'auto'
thresholds = {'static_ratio': 0.5}
```

**判定过程**：
1. `mode == 'auto'`，继续自动判定
2. `camera_comp_enabled == True`，继续判断
3. `mean_static_ratio (0.663) > thresholds['static_ratio'] (0.5)`，条件满足
4. 返回 `'static'`

**结果**：`scene_type = 'static'`

### 4.2 示例2：动态场景判定

**输入数据**：
```python
temporal_stats = {
    'mean_static_ratio': 0.337,  # 静态区域占比 33.7%
    ...
}
camera_comp_enabled = True
mode = 'auto'
thresholds = {'static_ratio': 0.5}
```

**判定过程**：
1. `mode == 'auto'`，继续自动判定
2. `camera_comp_enabled == True`，继续判断
3. `mean_static_ratio (0.337) > thresholds['static_ratio'] (0.5)`，条件不满足
4. 返回 `'dynamic'`

**结果**：`scene_type = 'dynamic'`

### 4.3 示例3：相机补偿未启用

**输入数据**：
```python
temporal_stats = {
    'mean_static_ratio': 0.8,  # 静态区域占比 80%
    ...
}
camera_comp_enabled = False  # 未启用相机补偿
mode = 'auto'
thresholds = {'static_ratio': 0.5}
```

**判定过程**：
1. `mode == 'auto'`，继续自动判定
2. `camera_comp_enabled == False`，条件不满足，跳过静态判定
3. 直接返回 `'dynamic'`

**结果**：`scene_type = 'dynamic'`（即使静态区域占比很高）

**原因**：未启用相机补偿时，相机运动会被误判为物体运动，因此统一判定为动态场景。

### 4.4 示例4：强制模式

**输入数据**：
```python
temporal_stats = {
    'mean_static_ratio': 0.2,  # 静态区域占比 20%
    ...
}
camera_comp_enabled = True
mode = 'static_scene'  # 强制静态场景
thresholds = {'static_ratio': 0.5}
```

**判定过程**：
1. `mode == 'static_scene'`，直接返回 `'static'`
2. 不进行自动判定

**结果**：`scene_type = 'static'`（忽略实际数据）

## 五、判定条件总结表

| 条件 | 场景类型 | 说明 |
|------|---------|------|
| `mode == 'static_scene'` | `'static'` | 强制静态场景 |
| `mode == 'dynamic_scene'` | `'dynamic'` | 强制动态场景 |
| `mode == 'auto'` AND `camera_comp_enabled == False` | `'dynamic'` | 未启用相机补偿，统一判定为动态 |
| `mode == 'auto'` AND `camera_comp_enabled == True` AND `mean_static_ratio > 0.5` | `'static'` | 静态区域占比超过50% |
| `mode == 'auto'` AND `camera_comp_enabled == True` AND `mean_static_ratio <= 0.5` | `'dynamic'` | 静态区域占比小于等于50% |

## 七、注意事项

### 7.1 相机补偿的重要性

- **必须启用相机补偿**：只有在 `camera_comp_enabled == True` 时，场景类型判定才有效
- **未启用时的行为**：无论 `mean_static_ratio` 是多少，都会判定为 `'dynamic'`

### 7.2 阈值调整

- **默认阈值 0.5**：表示静态和动态区域各占一半时作为分界点
- **可自定义**：可以通过 `thresholds` 参数自定义阈值
- **调整建议**：
  - 提高阈值（如 0.6）：更严格，只有静态区域占比很高才判定为静态
  - 降低阈值（如 0.4）：更宽松，静态区域占比稍高就判定为静态

### 7.3 静态区域检测的影响

- **依赖光流质量**：静态区域检测依赖光流计算的准确性
- **阈值敏感性**：`flow_threshold_ratio` 或 `flow_threshold` 会影响静态区域检测，进而影响 `mean_static_ratio`

---

## 八、总结

场景类型判定基于以下关键要素：

1. **核心指标**：`mean_static_ratio`（平均静态区域比例）
2. **判定阈值**：`static_ratio = 0.5`（默认值）
3. **判定条件**：
   - `mean_static_ratio > 0.5` → `'static'`
   - `mean_static_ratio <= 0.5` → `'dynamic'`
4. **前提条件**：必须启用相机运动补偿（`camera_comp_enabled == True`）
5. **模式覆盖**：可以通过 `mode` 参数强制指定场景类型

判定逻辑简单明确，主要依赖静态区域占比这一核心指标。
